# しくみ

Onecarat Agent Office（1.0、小窓版）のしくみを、短くまとめます。

## 1. 全体の流れ

情報は一方向にだけ流れます。Claude Code から小窓へ届くだけで、小窓から Claude Code へ戻る道はありません。

```
Claude Code（利用者が PowerShell で使う）
   │  Hook（決まった場面で、裏でコマンドを呼ぶ）
   ▼
転送スクリプト  plugin/…/scripts/forward.mjs
   │  必要な項目だけを取り出して、127.0.0.1 に送る
   ▼
小窓アプリ  onecarat-agent-office.exe（1 つだけ動く）
   │  セッションごとに分けて、メモリに置く
   ▼
小窓（セッションごとに 1 枚）
      自分のセッションのイベントを読み、棒人間を描く
```

## 2. 部品

| 部品 | 場所 | 役目 |
|---|---|---|
| Hook の登録 | `plugin/onecarat-agent-office/hooks/hooks.json` | 11 種類のイベントで、転送スクリプトを裏で呼ぶ（[hook-events.md](hook-events.md)） |
| 転送スクリプト | `plugin/onecarat-agent-office/scripts/` | Hook の入力から必要な項目だけを取り出し、小窓アプリに送る。アプリが動いていなければ何もしない |
| 小窓アプリ | `src-tauri/`（Rust、Tauri 2） | 送られてきたイベントを受け取り、セッションごとの窓に振り分ける。窓を開く・並べる・閉じる |
| 画面 | `packages/office-ui/` | イベントを状態に直し、棒人間と背景を描く |
| 状態への変換 | `packages/adapter-claude-code/`、`packages/domain/` | Hook の入力 → イベント → 状態 → 表情としぐさ。自動テストがある |
| 起動スクリプト | `packages/launcher/` → `plugin/…/dist/office.mjs` | アプリを起動・終了する |

## 3. 小窓アプリの中

- **アプリは 1 つ、窓は複数。** 待ち受けるポート（既定は 47821）を 1 つのアプリしか使えないことを利用して、二重起動を防いでいます。2 つ目は起動してもすぐに終わります。
- **窓の割り当て。** イベントの `session_id` を見て、そのセッションの窓に入れます。初めてのセッションなら、新しい窓を開きます（起動直後の「待っている窓」があれば、それを使います）。窓は最大 8 枚です。
- **窓の位置。** 1 枚目は主モニターの右上。2 枚目からは下へ並べ、下まで埋まったら左の列に移ります。窓が閉じて空いた場所は、次の窓が使います。
- **窓はイベントを取りに来る。** 各窓は 0.2 秒ごとに「自分の窓あての新しいイベント」をアプリに尋ねます。アプリは、その窓のセッションのイベントだけを返します。別のセッションのイベントが混ざることはありません。
- **窓が呼べる命令は 3 つだけ。** 「自分あてのイベントを読む」「自分のタイトルを変える（フォルダ名と、承認待ちを表す自分の言語の文言）」「お別れが終わったので自分を閉じる」。ほかの命令や、Tauri の機能（ファイル、シェルなど）は、窓には許可していません。
- **セッションが終わったら。** `SessionEnd` が届くと、棒人間がお別れをして、窓が閉じます。その前に同じフォルダで新しいセッションが始まった場合（`/clear` など）は、同じ窓を新しいセッションが引き継ぎます。
- **最後の窓が閉じたら、アプリも終わります。**

## 4. アプリと転送スクリプトの約束

- アプリは起動すると、`%LOCALAPPDATA%\onecarat-agent-office\bridge.json` に、ポート番号・起動ごとの合言葉（トークン）・プロセス番号を書きます。終了するときに消します。
- 転送スクリプトは、このファイルがなければ何もせずに終わります。ファイルがあっても、書いたプロセスがもう動いていなければ、通信しません。
- 送る前に、相手が本当にこのファイルを書いたアプリかを確かめます（合言葉を知っていることの証明を、合言葉そのものは送らずに求めます）。確かめられたときだけ、イベントを送ります。
- アプリが受け付けるのは 4 つだけです。`GET /api/health`（上の確認）、`POST /hook`（イベント）、`POST /api/show`（閉じた窓をまた出せるようにする）、`POST /api/shutdown`（終了）。あとの 3 つには合言葉が必要です。

## 5. 画面

- オフィスの絵は SVG です。高さを 480 単位に固定し、幅は窓の形に合わせて変えます。窓を大きくすると、絵も大きくなり、机の数も増えます。
- 机に入りきらないサブエージェントは描かず、右上に「+3」のように数で示します。机が空くと、順に入ってきます。
- 承認待ちの表示（帯と枠）は、絵の拡大・縮小と関係なく、決まった大きさで描きます。窓をいちばん小さくしても読めるようにするためです。帯の文字は、窓の高さと幅の両方に合わせます（英語の文言は日本語より長いため）。
- 窓は、ふつうのアプリと同じようにタスクバーにしまえます（最小化）。しまっている間も、窓は自分のイベントを読み続けます。ブラウザの部品は、見えていないページのタイマーを遅くします（5 分を過ぎると 1 分に 1 回）。それでは承認待ちが伝わるのが遅れるので、この遅くする動きを起動時の指定で止めています（`src-tauri/src/main.rs` の `open_window`）。しまっている間に承認待ちになると、タイトルが変わり、タスクバーのボタンが光ります。
- 表示は日本語と英語です。Windows の表示言語が日本語なら日本語、それ以外は英語で、設定はありません。文言は `packages/domain/src/i18n.ts` の 1 か所にまとめ、窓・タイトルバー・起動スクリプトが同じ表を使います。
- 背景は、PC の時計の「時」で決めます（朝 5 時〜、昼 10 時〜、夕方 16 時〜、夜 19 時〜）。15 秒ごとに時計を見直すので、開いたままでも切り替わります。夜は、棒人間が夜空の前でも見えるように、全体を暗い配色にします。

## 6. 保存しないもの

- イベントは、アプリのメモリにだけ置きます。窓ごとに最大 4000 件で、古いものから捨てます。窓が閉じると、その窓のぶんは消えます。
- 設定ファイルはありません。窓の位置や大きさも覚えません（起動するたびに右上から並べます）。
- ディスクに書くのは、上の `bridge.json`（動いている間だけ）と、窓を表示する部品（WebView2）が自分で作るキャッシュ（`%LOCALAPPDATA%\com.onecarat.agent-office`）だけです。
